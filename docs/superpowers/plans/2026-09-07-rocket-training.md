# 训练与奖励实验页

用户已同意结合教学训练与真实 PPO 的方向；保留本地预览，内联实现。

目标：在 /play/rocket/train 通过实际浏览器计算展示评分、参数更新、训练前后对照。沿用白底蓝灰技术风格。

## 实现顺序
1. tests/rocket-training.test.mjs：先验证评分守恒、确定性、无学习评估不修改参数、训练确实更新参数与最佳记录。
2. lib/rocket/training.ts：复用 physics.mjs，每 0.05 秒决策。教学单神经元输入 h/50、v/20，三个可训练系数；sigmoid 输出油门。交叉熵参数搜索每轮 24 候选，保留最高分 6 个更新均值与标准差。固定种子；所有飞行真实计算。安全、油耗、时间三个评分权重。改变规则重置训练，避免不可比曲线混合。
3. app/play/rocket/train/page.tsx、training-lab.tsx、training.module.css：独立完整实验页，规则控制、播放/暂停/拖动飞行、训练轮次曲线、系数与筛选解释、同条件前后比较、测试高度。按帧分批计算候选，卸载取消。明确非 PPO、非原模型训练历史，不保证每轮提升。
4. 游戏及推理页面增加双向入口。手机单列、平板纵向优先完整实验、桌面双列，44px 控件，图表不依赖悬停。
5. node --test tests/rocket-training.test.mjs；npm run lint；npx vinext build；检查新路由与交互和多端尺寸。

真实 PPO 部分复用现有推理页；没有阶段检查点时不显示虚构的原项目训练回放。此页训练数据只保留当前会话，刷新重置。不会连接真实 AI 服务。
