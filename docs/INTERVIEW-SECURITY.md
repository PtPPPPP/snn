# 入社笔试的身份与权限

笔试链接直接发到群里，考生打开后填写姓名、学号即可作答。不需要 ChatGPT 账号、准考码或管理员提前登记。学院 / 专业、年级为选填。阅卷仍使用独立的管理员认证、白名单和 DB 绑定。

## 公开登记与身份绑定

服务器验证姓名、学号及字段长度，规范化学号，生成笔试身份编号。每轮笔试中，学号和浏览器绑定由数据库唯一约束限制：同一学号不能重复登记，同一浏览器不能切换为其他考生。姓名及已绑定的个人信息不能通过交卷请求改写。

浏览器凭证由服务器随机生成，存放在 Secure、HttpOnly、SameSite=Lax 的 `__Host-` Cookie 中。数据库只保存 SHA-256 摘要。公开会话接口仅返回当前浏览器自己的身份和提交回执，不提供答案、评分或其他考生信息。

这是一份公开填写的表单，姓名、学号属于考生自行填写的信息，不能当作学校实名认证。没有接入学校身份源，也不能证明填写人就是学号本人。设备约束识别浏览器配置；清空 Cookie、无痕模式或不同浏览器不等于可靠识别物理设备。同一已登记学号仍会被后端拒绝重新绑定，需负责人核实后恢复。

## 阅卷授权

阅卷页、答卷列表、完整答案、评分参考、评分保存和设备恢复接口均在服务器检查管理员白名单。公开登记和设备 Cookie 不授予阅卷权限。

管理员身份来自 Sites 验证后传递的 `oai-authenticated-user-id` / `oai-authenticated-user-email`，不接受请求体中的角色、邮箱或用户编号。自托管时，必须由可信认证代理移除客户端伪造的这些头并写入验证结果，不能将原始 Worker 直接公开。

`SNN_INTERVIEW_ADMIN_EMAILS` 保留现有邮箱白名单。可配置 `SNN_INTERVIEW_ADMIN_USER_IDS` 使用本 Site 范围内的稳定用户 ID；配置后以 ID 白名单为准。没有白名单或登录信息时拒绝访问。个性化页面和接口使用 `private, no-store`。

## 提交与恢复

答卷编号、题目和分值由服务器确定；身份字段取自已绑定记录。混合卷包含 8 道固定客观题、2 道简答、各 1 道方向与情景选答，共 12 题。同一身份只创建一份答卷，重试返回原回执，不覆盖答案。刷新恢复已绑定身份和已提交回执；尚未实现未提交答案的自动保存。

写接口验证同源 Origin、JSON 类型和请求体字节上限。客观题仅接受本题有效选项，多选拒绝空选、重复或题外选项。简答每题两步，每步最多 120／150 字；方向／情景题每题四步，通常每步最多 180 字，短通知与汇总说明分别限制 100、80 字。服务器拒绝缺失、题外步骤和过长回答。数据写入使用参数化语句和 D1 事务批次，唯一约束防止并发重复绑定或提交。

评分保存携带修订号。服务器原子比较并递增修订号，过期评分返回 409；页面保留当前修改，并提供放弃当前修改后载入最新评分的操作。客观题在提交时按私有答案快照计分，评分保存时重新核算并拒绝改写自动分数。单选／判断对得满分、错得零分；多选全对满分，少选且无错选得一半，错选零分，规则在考生页面明示。正确答案仅随获授权阅卷详情返回。

主观题每步选择零分、半分值或满分，由服务器合计；全部评分点未判完时该题仍未完成，允许保存进度。客观题已自动计分不代表整卷完成。旧版保留原题目和评分快照；最早自由文本版仍使用原分数范围及 0.5 分步长。

更换浏览器时，负责人先核实本人身份，再解除原绑定，让本人在新浏览器填写原姓名、学号。恢复沿用原身份及已提交答卷，不生成准考码。由于表单没有独立实名认证，负责人应当核实后让本人及时完成重新绑定。

身份绑定、提交、评分和设备恢复记录保存操作人、时间和必要的变更内容，与业务变更一并提交。原始设备凭证不进入操作记录。

## 数据兼容与验证

题库升级追加迁移 0003，为答卷增加独立题库版本和评分标准快照，不删除旧答卷或重写已应用迁移。同一招新轮次保持原身份／学号唯一限制。新答卷由服务器保存题目、答案及评分标准，今后改题也不会改变已交卷的判据。旧答卷使用冻结的旧评分参考及原自由文本答案。尚未提交的过期题库请求返回明确的更新提示；已提交身份的重试返回原回执。

历史准考码表保留以兼容已有记录，发码接口和界面已移除。已绑定的历史身份无需原码即可继续使用；历史明确停用的身份仍拒绝进入。旧答卷继续可阅卷，已提交学号不能重复登记。题库设计与阅卷口径见 [题库说明](./INTERVIEW-QUESTION-BANK.md)。
