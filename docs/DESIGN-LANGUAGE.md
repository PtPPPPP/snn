# SNN · 炭黑字符设计语言

2026-10-07，本地第一版。由用户确认：全站炭黑；字符与点阵构成节点和连接；所有有效连接按数值着色。当前线上版本尚未更新。

## 视觉核心

炭黑是工作与阅读的底色。细线划分内容，字符构成计算路径，数字构成信息中心。界面保持规整，连接仅轻微弯曲。不增加无意义字符、虚构支路、巨大管道或环境动画。Logo 保留原资产。

## Token 来源

`lib/design/tokens.ts` 是唯一基础来源，包含材质、字体、尺寸、间距、圆角、动效和数值配色锚点。`scripts/generate-design-tokens.mjs` 生成 `app/design-foundation.css`。`app/design-tokens.css` 保留旧组件语义别名。Three.js、SVG 与数值配色直接复用同一来源。

正文 16px；常用标签 14px；元信息 12px。数值使用 Geist Mono 等宽字体并对齐数字。中文沿用现有系统字体回退。间距使用 4、8、12、16、24、32、48、64px 的节奏；界面圆角 0–4px，以薄边框而非阴影区分层次。交互目标通常 48px，允许原有紧凑控件的44px目标。焦点保持可见。

## 三套语义严格分开

- 真实类别：空心方点与实心像素点；位置和形状不随数值变号改变。
- 计算数值：负蓝紫，零附近低亮中性，正绿→黄→红；数字和正负符号始终保留。
- 操作状态：中性轮廓、背景与明确文字。完成、选中和错误不借用热力色判断。

## 连续数值标尺

| 数值 | 色彩锚点 |
|---|---|
| −2 | #a58bf5 |
| −1 | #6b9be8 |
| 0 | #66665f |
| +0.5 | #7ecb91 |
| +1.25 | #e2cc72 |
| +2 | #ec806b |

`valueColor(value)` 使用固定 −2…+2 标尺，锚点之间连续 RGB 插值。正负两段共享零锚点。超范围颜色饱和，数字不裁剪。8位屏幕量化不定义语义色档。该标尺不得表示类别、正确率或概率。

连接按该路实际加权贡献着色；权重固定写在线旁。节点按当前输出着色，中心显示真实数字。中间插值显式说明为“显示过渡”。负贡献先进入总和，再对总和激活。

## 教学图形

节点由字符轮廓构成，符号 +／−／: 分别对应正／负／零；连接采用相同符号形成细弧线。字符是数据与结构的表达，不是撒在边框上的装饰。零权重可在简图省略，但权重表必须完整说明。空间曲面使用同一数值标尺，白色零交线与真实类别标记保留。

当前手工网络为 h₁=x₁、h₂=x₂、a₃=x₁+x₂−1、h₃=ReLU(a₃)，最终 s=h₁+h₂−2h₃−0.5。前两路是直接传递。分类原始点固定在 (x₁,x₂,0)，分数面高度来自 s。四角点分类成功不推广为连续 XOR 泛化能力。

## 本轮应用范围

全站共享炭黑底色、表面、文字、边框、控件与圆角。首页实验入口与非线性教学图复用字符网络。非线性空间的 Three.js 点阵、曲面、二维预览、当前分数与图例使用统一连续配色。大型火箭网络仍保留现有绘制方式及其既有独立数值标尺，后续按此规范迁移；本轮不改它们的训练与推理逻辑。
