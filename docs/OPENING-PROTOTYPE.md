# 分类开场原型

本次只实现已确认的开场：抽象两类点、先看示范、正视转斜视、明确换成 XOR、留下改变表示/空间的疑问。主入口 `/learn/neural-networks`；以前的完整文章保留在 `/learn/neural-networks/archive`，旧章节地址重定向到其归档锚点。版本 978ce4587ecbbfb3f61f373beb0929804e79e608 仍可恢复。

- 第一组8点由x₁=0完全分开。第二组是四个XOR角点；尝试边界x₁+x₂=−0.1只分对3/4，右上0类点分错。
- 任意直线不能完全分开四角点的依据是同类线段的交点，不是一次试线的经验结论。
- 正交相机的倾角小于π/2，投影保持可逆；数据点始终z=0，摄像机不改变标签或分类。此处没有折叠、特征变换或训练。
- 自动示范约11.2秒，仅播放一轮。可暂停、重播、查看两组、切换视角；手机保留纵向阅读，横拖改变视角；键盘方向键与Home可用。隐藏页面/图离开主要视野时暂停。减弱动态不自动播放，直接查看静态端点。
- 示例图层与预测底色均由实际线性分类计算。数据切换时淡出/淡入并明确改组，不把点的移动伪称成分类成功。
- 图示已从实际SVG栅格化检查；数学与服务端输出有测试。未执行完整浏览器触摸、手机排版或屏幕阅读器验证，私人站鉴权与云浏览器限制仍存在。
