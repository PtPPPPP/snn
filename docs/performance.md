# 首屏性能维护

网站维持现有视觉和交互。首页、课程、SNN AI 的构建会自动执行
`scripts/performance-budget.mjs`，计算首批静态依赖的 gzip 体积以及主要字库、标志的原始体积：

| 页面 | 预算 |
| --- | ---: |
| 首页 | 370 KiB |
| 神经网络课程 | 560 KiB |
| SNN AI | 700 KiB |

预算覆盖首批 JS、CSS（包括异步备用字体规则）和主要字体、标志；不代表完整页面加载时间，也不包括 HTML、用户输入或按需模块。公式排版器不得被直接引入首批依赖。构建超过预算会失败，修改预算应同时说明真实需求和性能影响。浏览器/CDN 实际压缩方式可能与构建检查不同。

`scripts/prepare-fast-fonts.py` 从原始字体生成首页、课程和其他页面的去重字符子集；备用字库的选择规则以非阻塞样式表加载，避免拖延首屏文字。新增文案较多时应重新生成并提交产生的新文件及更新后的 CSS、JSON。旧的哈希文件保留给尚未更新的客户端。

构建会用当前版本的 React 应用渲染六个公开入口，包括首页、课程、AI 对话外观、火箭挑战、推理和训练。HTML 与脚本随同一版 Worker 发布。访问者打开页面时即可收到正文、样式与交互脚本的地址。课程参数、飞行模拟和聊天记录仍由浏览器各自初始化。

公开入口使用浏览器文档导航，支持推测加载的浏览器可在悬停或触摸目标时预取该页 HTML。窄屏的导航开关使用原生 HTML 折叠控件。页内章节锚点就地跳转。

匿名、无查询参数的 HTML 请求可命中本次发布的文档，响应头为 `X-SNN-Page-Cache: STATIC`。浏览器可使用 ETag 验证已有副本。资源缺失时沿用服务端渲染和按发布版本划分的短期边缘缓存。含身份、Cookie、查询参数的请求，以及 RSC、API 与笔试页面，都走原有处理流程。

实际加载速度还依赖访问者网络、区域和设备；应在 Cloudflare 的真实用户指标可用时关注首屏呈现、交互与页面稳定性，并结合目标地区网络观察。构建预算与边缘缓存都不能替代真实用户数据或保证某个固定秒数。
