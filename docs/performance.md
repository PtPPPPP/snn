# 首屏性能维护

网站维持现有视觉和交互。首页、课程、SNN AI 的构建会自动执行
`scripts/performance-budget.mjs`，计算首批静态依赖的 gzip 体积以及主要字库、标志的原始体积：

| 页面 | 预算 |
| --- | ---: |
| 首页 | 370 KiB |
| 神经网络课程 | 560 KiB |
| SNN AI | 700 KiB |

预算只覆盖首批 JS、CSS 和主要字体、标志；不代表完整页面加载时间，也不包括 HTML、用户输入或按需模块。公式排版器不得被直接引入首批依赖。构建超过预算会失败，修改预算应同时说明真实需求和性能影响。浏览器/CDN 实际压缩方式可能与构建检查不同。

`scripts/prepare-fast-fonts.py` 从原始字体生成首页、课程和其他页面的去重字符子集；新增文案较多时应重新生成并提交产生的新文件及更新后的 CSS、JSON。旧的哈希文件保留给尚未更新的客户端。

Cloudflare Worker 仅对匿名、无查询参数的首页和神经网络课程 HTML 使用短期边缘缓存；带身份、Cookie、RSC 导航、API 和其他页面均不进入该缓存。缓存键包含 Worker 版本，每次部署自动隔离旧页面；缓存不可用时回退到正常渲染。静态哈希资源继续长期缓存。

实际加载速度还依赖访问者网络、区域和设备；应在 Cloudflare 的真实用户指标可用时关注首屏呈现、交互与页面稳定性，并结合目标地区网络观察。构建预算与边缘缓存都不能替代真实用户数据或保证某个固定秒数。
